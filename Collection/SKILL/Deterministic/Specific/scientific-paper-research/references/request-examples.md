# Request examples

One JSON object per run. Unknown fields are rejected. Use forward slashes in paths.

## TOPIC_SEARCH

User: "Latest papers on AI for lung cancer detection on CT, about 8."

```json
{"mode": "TOPIC_SEARCH", "result_count": 8, "freshness": "latest",
 "concepts": [{"slot": "technology", "term": "artificial intelligence"},
              {"slot": "disease", "term": "lung cancer"},
              {"slot": "modality", "term": "CT"}]}
```

## KEYWORD_SEARCH

User: `Search: ("lung cancer") AND ("computed tomography") since 2022, download them`

```json
{"mode": "KEYWORD_SEARCH", "query": "(\"lung cancer\") AND (\"computed tomography\")",
 "year_from": 2022, "download": true}
```

User gives a raw Scopus query:

```json
{"mode": "KEYWORD_SEARCH", "query": "TITLE-ABS-KEY(\"pedestrian simulation\") AND PUBYEAR > 2022",
 "query_is_scopus_syntax": true, "result_count": "batch"}
```

Without `ELSEVIER_API_KEY` the same requests run on OpenAlex (`result.provider: openalex`). Boolean
operators in `query` must then be uppercase `AND` / `OR` / `NOT`; `query_is_scopus_syntax: true` is rejected.

## DOI_DOWNLOAD

```json
{"mode": "DOI_DOWNLOAD", "dois": ["10.1016/j.cell.2020.01.001", "https://doi.org/10.1038/s41586-020-2012-7"],
 "outdir": "./downloads"}
```

With a report (recommended for batches; rerunning skips verified files):

```powershell
python -X utf8 scripts/run.py --request request.json --report downloads/report.md
```

## TITLE_DOWNLOAD (no API key needed: Crossref, then OpenAlex)

```json
{"mode": "TITLE_DOWNLOAD", "titles": ["Attention Is All You Need", "Black-Box Adversarial Attacks Against SQL Injection Detection Model"]}
```

## PAPER_ANALYSIS (step 1; step 2 request is generated by the script)

```json
{"mode": "PAPER_ANALYSIS", "pdf_path": "C:/papers/smith2024.pdf"}
```

## BATCH_ANALYSIS

```json
{"mode": "BATCH_ANALYSIS", "pdf_paths": ["C:/papers/a.pdf", "C:/papers/b.pdf"]}
```

## Clarification case

User: "Find RCTs on metformin in a specific population" (population not named).

```json
{"mode": "TOPIC_SEARCH",
 "concepts": [{"slot": "intervention", "term": "metformin"}, {"slot": "study_type", "term": "randomized controlled trial"}],
 "unresolved_filters": ["population"]}
```

Output: `status: clarification_required`, exit 3. Relay `clarification.relay_verbatim` and stop.

## Invalid request

```json
{"mode": "DOI_DOWNLOAD", "doi": "10.1000/x"}
```

Output (exit 2):

```json
{"mode": "DOI_DOWNLOAD", "status": "invalid_request", "request": {"mode": "DOI_DOWNLOAD", "doi": "10.1000/x"},
 "result": null, "clarification": null,
 "error": {"code": "invalid_request", "message": "unknown field 'doi' is not allowed in DOI_DOWNLOAD", "setup_hint": null},
 "next_command": null, "contract_version": "1.0"}
```
